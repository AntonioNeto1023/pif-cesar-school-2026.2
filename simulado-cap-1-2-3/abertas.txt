a) O while testa a condição antes de executar e pode executar zero vezes. O do-while testa depois de executar e executa pelo menos uma vez.

b) O for é mais adequado quando sabemos a quantidade de repetições ou quando temos uma variável de controle com inicialização, condição e incremento.

c) É um erro de lógica, não de compilação. O ponto e vírgula cria um laço com corpo vazio. Se a condição for verdadeira e nunca mudar, o programa ficará em um loop infinito.

6 -

a) O erro ocorre porque a variável soma foi declarada dentro do bloco do for. Por isso, ela não pode ser acessada no printf que está fora desse bloco.

b) O laço começa em i = 1.

i = 1, 2, 3 e 4 são processados normalmente.

Quando i = 5, o continue pula o restante daquela iteração.

i = 6 e 7 são processados normalmente.

Quando i = 8, o break encerra o laço imediatamente.

Portanto, os valores processados são 1, 2, 3, 4, 6 e 7.

c) Código corrigido:

#include <stdio.h>
#include <stdlib.h>

int main() {
int i;
int soma = 0;

```
for (i = 1; i <= 10; i++) {
    if (i == 5)
        continue;

    if (i == 8)
        break;

    soma += i * i;
}

printf("Soma final = %d\n", soma);

system("PAUSE");

return 0;
```

}

1² + 2² + 3² + 4² + 6² + 7²

= 1 + 4 + 9 + 16 + 36 + 49

= 115
